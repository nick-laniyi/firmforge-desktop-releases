# FirmForge Trader — Desktop Release Assets

Public download mirror for the FirmForge Trader desktop app.

Installers are attached to the [Releases](https://github.com/nick-laniyi/firmforge-desktop-releases/releases) — grab the latest for your OS.

The source repo (`nick-laniyi/firmforge`) is private. This mirror exists so anonymous download URLs work for anyone the operator sends the app to.

See `docs/DESKTOP_RELEASES_SETUP.md` in the source repo for the release pipeline docs.
